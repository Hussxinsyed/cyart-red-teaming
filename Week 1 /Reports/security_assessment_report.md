# Security Assessment Report

## Executive Summary

During Week 1, I studied the fundamentals of Red Teaming and explored how attackers gather information, identify vulnerabilities, and document findings. The practical activities focused on network scanning, service enumeration, and understanding exploitation concepts using a controlled lab environment.

## Findings

### Network Scanning

Nmap was used to identify open ports and running services on the target system. Service version detection provided information about the applications exposed on the network.

### Vulnerability Assessment

Metasploit Framework was explored to understand how known vulnerabilities can be validated in a lab environment. Different modules and workflows were reviewed to understand the exploitation process.

### Security Observations

The exercises demonstrated how exposed services and outdated software may increase the attack surface of a system. Proper patch management and service hardening are important to reduce security risks.

## Recommendations

* Regularly update operating systems and applications.
* Disable unnecessary services.
* Conduct routine vulnerability assessments.
* Monitor network activity for suspicious behavior.
* Follow security best practices for system administration.

## Conclusion

This week's activities provided a practical introduction to Red Teaming concepts and helped build foundational knowledge in reconnaissance, vulnerability assessment, and security reporting.
