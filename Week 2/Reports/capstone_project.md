# Capstone Project

In this project I performed a basic security assessment in a lab environment.

First I used Nmap to scan and identify services on the target machine.

After finding vulnerable services, I used Metasploit for exploitation testing.

Then I used Wireshark to observe network communication and traffic.

This project helped me understand the workflow from reconnaissance to analysis and documentation.

Recommendations:
- Keep systems updated
- Disable unnecessary services
- Monitor suspicious activity
