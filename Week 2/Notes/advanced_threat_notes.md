# Advanced Threat Analysis

In this task I learned about advanced cyber threats and how attackers plan attacks.

I learned STRIDE which is used to identify security threats:

Spoofing – pretending to be another user  
Tampering – modifying data  
Repudiation – denying actions  
Information Disclosure – exposing information  
Denial of Service – making service unavailable  
Elevation of Privilege – getting higher access

I also learned about MITRE ATT&CK. It helps understand attacker behavior and different attack techniques.

Some advanced attacks include:
- APT attacks
- Supply chain attacks
- Zero-day vulnerabilities

This helps security teams understand threats better.
