# Capstone Report

## Scenario

A simulated red team assessment was conducted in a controlled lab environment to understand advanced attack workflows.

## Activities Performed

- Reviewed MITRE ATT&CK techniques
- Observed encrypted TLS traffic using Wireshark
- Explored Metasploit framework structure
- Studied cloud security risks and IAM concepts
- Reviewed adversary emulation methodologies
- Studied living-off-the-land techniques

## Key Learnings

The assessment demonstrated how encrypted traffic can still expose metadata patterns useful for monitoring. Cloud environments require strict permission management to prevent privilege abuse. Adversary emulation helps organizations improve defensive readiness and detection capabilities.

## Recommendations

- Improve traffic monitoring
- Enforce MFA
- Restrict excessive permissions
- Monitor scripting activity
- Conduct regular security assessments
