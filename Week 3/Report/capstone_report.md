# Capstone Report

## Executive Summary
A simulated red team workflow was reviewed from reconnaissance to post-exploitation in a controlled lab environment.

## Findings
- Recon tools helped identify information about targets.
- Nmap identified services and open ports.
- Metasploit was used to study vulnerability testing methods.

## Recommendations
- Keep systems updated.
- Disable unnecessary services.
- Use network monitoring and strong authentication.
