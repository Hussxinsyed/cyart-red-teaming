# OSINT Notes

OSINT means Open Source Intelligence.

Passive Recon:
Information gathering without directly interacting with systems.

Examples:
- WHOIS
- DNS lookup
- Search engines
- Shodan

Active Recon:
Direct interaction with systems.

Examples:
- Nmap scans
- Service enumeration

Shodan helps identify publicly exposed devices and services.

MITRE ATT&CK maps attacker behavior.

Tactic = objective

Technique = method used
